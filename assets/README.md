The mark is a section through a sailing hull: the deck arc you see, the dashed
waterline, and below it the fin keel painted in the oxide red of antifouling
paint — the only colour in the system, and it sits where nobody looks. A
cross-section rather than a boat silhouette because the claim is about
structure, not sailing. The wordmark is lowercase Bricolage Grotesque, set
narrow like a chart label; body and code use IBM Plex Sans and IBM Plex Mono.

Palette: paper `#EEF1F4`, ink `#10202B`, water `#2F6F8F`, hull red `#B23A2F`.
